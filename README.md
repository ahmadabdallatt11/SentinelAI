Sentinel-IDS is an advanced, real-time Network Intrusion Detection System (NIDS) integrated with a machine learning classification pipeline and an automated AI incident analysis engine powered by Google Gemini. It captures network traffic packets live using Scapy, evaluates packet features using a trained Random Forest Classifier to instantly flag anomalies, and automatically generates professional Security Operations Center (SOC) incident reports with technical remediation steps. The system features an interactive dashboard built with React, Tailwind CSS, and WebSockets for real-time telemetry streaming, alongside SQLite integration to log historical incidents and export database files directly from the interface.
